📝 How to Add & Edit Blog Posts

To manage your blog content:

  1. Open the file: blog/index.html in your code editor
  2. Find the <script> section at the bottom with the defaultPosts array
  3. To add a new post: Add a new object to the array:
    {id: 7, title: "Your Title", excerpt: "Summary here", content: "Full content...", date: "Aug 20, 2026", readTime: 5}
  4. To edit a post: Modify the text in the corresponding post object (don't change the ID)
  5. To delete a post: Remove the entire post object from the array
  6. Save the file and commit to GitHub
  7. Your site will automatically show the updated posts

💡 Tip: The posts are stored in JavaScript (browser localStorage) for now. Once you're ready for a permanent backend solution, I can help you migrate to a PHP/database system.
